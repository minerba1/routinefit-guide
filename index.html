모든 분께 맞습니다

루틴핏은 특정 나이나 질환에 국한되지 않습니다. 처음 앱을 시작할 때 작성하는 건강 설문을 바탕으로, AI가 나에게 딱 맞는 방식으로 도움을 드립니다.

💊
만성질환 관리 중인 분
혈압약, 당뇨약 복용 중이라면 복약 시간과 수치 변화를 자동으로 기록하고 추이를 확인할 수 있어요.
혈압·혈당·복약 추적
⚖️
체중 조절이 목표인 분
음식 사진 한 장으로 칼로리와 영양소를 분석해 드려요. 식사 패턴을 파악하면 무엇을 바꿔야 할지 보입니다.
식사 분석·체중 추이
🏃
운동 습관을 만들고 싶은 분
"오늘 30분 걸었어"라고 말하면 바로 기록됩니다. 주간 활동량을 한눈에 보고 꾸준히 이어갈 수 있어요.
운동 기록·주간 리포트
😴
수면·피로 개선이 필요한 분
취침·기상 시간을 기록하고 수면 패턴을 분석해 드려요. 피로 회복에 무엇이 영향을 주는지 파악할 수 있습니다.
수면 기록·패턴 분석
👨‍👩‍👧
가족 건강을 챙기는 분
부모님, 자녀, 배우자의 건강 관리를 도와주고 싶다면 그 대상에 맞게 AI가 맞춤 조언을 드립니다.
가족 맞춤 관리
🧘
스트레스·생활습관 개선 중인 분
음주, 흡연, 스트레스 수준도 기록할 수 있어요. 생활 전반을 기록하면 어디서 변화가 필요한지 보입니다.
생활습관 전반 기록
💡

앱 설치

앱스토어 없이
바로 설치할 수 있어요

루틴핏은 웹 기반 앱(PWA)입니다. 앱스토어 없이 스마트폰 홈 화면에 바로 추가할 수 있습니다.

🍎 아이폰 (Safari)
  1. Safari로 루틴핏 주소를 엽니다
  2. 하단 공유 버튼(□↑)을 누릅니다
  3. "홈 화면에 추가"를 선택합니다
  4. 오른쪽 위 "추가"를 누릅니다
🤖 안드로이드 (Chrome)
  1. Chrome으로 루틴핏 주소를 엽니다
  2. 오른쪽 위 메뉴(⋮)를 누릅니다
  3. "홈 화면에 추가"를 선택합니다
  4. "추가"를 누릅니다
📱
설치 후에는 일반 앱처럼 홈 화면에서 바로 실행할 수 있습니다. 인터넷 연결만 있으면 언제든 사용 가능합니다.
기능 안내

5개 탭, 이렇게 사용하세요

루틴핏은 5개의 탭으로 구성되어 있습니다. 각 탭을 눌러 사용 방법을 확인하세요.

💬
대화 탭 — 건강 기록의 시작
가장 많이 사용하게 될 핵심 탭입니다
AI 코치에게 오늘 있었던 일을 편하게 말하면, 자동으로 분류되어 타임라인에 저장됩니다. 어렵게 생각하지 마세요. 그냥 대화하듯 입력하면 됩니다.
🎤
음성으로 말하기
마이크 버튼을 누르고 편하게 말하세요
"아침에 혈압약 먹었어"
📷
사진 찍기
음식 사진 한 장이면 영양소 분석 완료
식판 사진 → 칼로리·영양소 자동 분석
⌨️
텍스트 입력
직접 타이핑해도 됩니다
"저녁 산책 20분, 혈당 105"
이렇게 말해보세요
→ "오늘 점심에 된장찌개랑 밥 먹었어"
→ "혈압 128/82 쟀어"
→ "오늘 헬스장 40분 다녀왔어"
→ "어제 밤 11시 취침, 오늘 아침 7시 기상"
✨
하루치 일정을 한꺼번에 붙여넣기할 수도 있어요. "오늘 하루: 7시 기상, 8시 아침 토스트, 12시 점심 비빔밥, 18시 헬스장 30분, 22시 취침" — AI가 자동으로 5개 항목을 분리해서 저장합니다.
📅
일정 탭 — 내 하루를 한눈에
대화 탭에서 기록한 내용이 자동으로 나타납니다
대화 탭에서 기록한 모든 내용이 시간 순서대로 타임라인에 정리됩니다. 직접 수정하거나 삭제할 수도 있습니다.
일
일간 뷰 — 오늘 하루의 기록을 시간 순서로 확인합니다. 각 항목을 눌러 수정하거나 삭제할 수 있습니다.
주
주간 뷰 — 이번 주 기록을 시간 그리드로 한눈에 봅니다. 어떤 요일에 어떤 활동을 했는지 패턴이 보입니다.
월
월간 뷰 — 이번 달 전체 기록을 달력 형태로 확인합니다.
📬
"어제 리포트" 버튼을 누르면 어제 하루 기록을 바탕으로 AI가 써준 건강 편지를 볼 수 있습니다.
📊
보고서 탭 — 변화를 숫자로 확인
기록이 쌓일수록 더 정확해집니다
기록이 쌓이면 AI가 주간·월간 건강 보고서를 만들어 드립니다. 체중, 혈압, 혈당의 변화 추이도 그래프로 확인할 수 있습니다.
1
수치 입력 — 우측 상단 📏 버튼을 눌러 체중, 혈압, 혈당을 직접 입력하거나, 대화 탭에서 말로 기록하면 자동으로 저장됩니다.
2
리포트 생성 — "주간 리포트" 또는 "월간 리포트" 버튼을 누르면 AI가 기록을 분석해 맞춤 보고서를 만들어 드립니다.
3
추이 확인 — 7일, 30일, 90일 단위로 수치 변화를 그래프로 확인할 수 있습니다.
📈
기록이 3일 이상(약 6~9끼) 쌓이면 "내 요리 철학 TOP 5"가 자동으로 분석됩니다. 내가 어떤 식습관을 가지고 있는지 확인해보세요.
👤
프로필 탭 — 나의 기본 정보
언제든 수정할 수 있습니다
이름, 나이, 키, 몸무게, 복약 정보를 입력하는 곳입니다. 정확하게 입력할수록 AI가 더 적절한 조언을 드릴 수 있습니다.
1
기본 정보 — 이름, 나이, 성별, 키, 몸무게를 입력합니다.
2
복약 정보 — 현재 복용 중인 약이 있다면 입력해두세요. AI가 복약 시간을 함께 관리해 드립니다.
3
건강 설문 — 프로필 화면에서 "건강 설문" 버튼을 눌러 상세 설문을 작성하거나 수정할 수 있습니다.
💪
InBody 체성분 측정 결과가 있다면 "InBody 체성분 입력"에 기록해두세요. AI가 더 정밀한 운동·식단 조언을 드릴 수 있습니다.
⚙️
설정 탭 — 데이터 관리
내 데이터는 내 기기에만 저장됩니다
데이터 백업, 복원, 앱 설치 가이드, 사용법 다시 보기 등을 이용할 수 있습니다. 모든 데이터는 내 기기에만 저장되며, 외부 서버로 전송되지 않습니다.
📤
데이터 내보내기 — 내 기록을 JSON 파일로 저장해 백업할 수 있습니다.
📥
데이터 불러오기 — 백업해둔 파일로 기록을 복원할 수 있습니다. 기기를 바꿀 때 유용합니다.
📖
앱 사용법 다시 보기 — 처음 안내 화면을 다시 볼 수 있습니다.
🧹
중복 일정 정리 — 실수로 중복 저장된 기록을 한 번에 정리합니다.
🔒
루틴핏의 모든 기록은 내 기기 안에만 저장됩니다. 인터넷에 업로드되거나 다른 사람이 볼 수 없습니다. 안심하고 솔직하게 기록하세요.

자주 묻는 질문

궁금한 점이 있으신가요?

자주 묻는 질문을 모았습니다. 눌러서 답변을 확인하세요.

🎤 음성 입력이 작동하지 않아요 ▼
마이크 권한이 허용되어 있는지 확인해 주세요. 스마트폰 설정 → 앱 권한 → 마이크에서 루틴핏(또는 브라우저)의 마이크 접근을 허용해 주세요. 아이폰의 경우 Safari에서만 음성 입력이 지원됩니다.
📅 기록했는데 타임라인에 안 보여요 ▼
대화 탭에서 AI가 응답을 완료한 후 기록이 저장됩니다. 응답이 끝나기 전에 탭을 이동하면 저장이 안 될 수 있습니다. 또한 타임라인은 오늘 날짜가 기본으로 표시되니, 날짜를 확인해 주세요.
📊 보고서가 생성되지 않아요 ▼
보고서 생성에는 인터넷 연결이 필요합니다. 또한 기록이 충분히 쌓여야 의미 있는 보고서가 만들어집니다. 최소 3일 이상 기록 후 시도해 보세요.
📱 기기를 바꿨는데 기록이 사라졌어요 ▼
루틴핏의 데이터는 기기 안에 저장됩니다. 기기를 바꾸기 전에 설정 탭 → "데이터 내보내기"로 백업 파일을 저장해 두세요. 새 기기에서 "데이터 불러오기"로 복원할 수 있습니다.
🔄 앱을 처음부터 다시 시작하고 싶어요 ▼
설정 탭 → "모든 데이터 삭제"를 누르면 프로필, 대화, 기록이 모두 초기화됩니다. 삭제 전에 반드시 "데이터 내보내기"로 백업을 해두세요.
💡 건강 설문은 꼭 다 작성해야 하나요? ▼
필수는 아닙니다. 설문 없이도 기본 기능은 모두 사용할 수 있습니다. 다만 설문을 작성할수록 AI가 나의 상태와 목표를 더 잘 이해해서 더 정확한 분석과 조언을 드릴 수 있습니다. 부담 없이 아는 것만 답해도 됩니다.
🍱 음식 사진 분석은 어떻게 하나요? ▼
대화 탭에서 카메라(📷) 버튼을 눌러 음식 사진을 찍거나 앨범에서 선택하세요. AI가 사진을 분석해 음식명, 칼로리, 주요 영양소를 알려드리고 자동으로 기록합니다.
